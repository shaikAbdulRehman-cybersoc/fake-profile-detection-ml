# fake-profile-detection-ml
An end-to-end Machine Learning project in Python and Google Colab designed to detect fake social media profiles using account metadata and classification algorithms. Uses the Kaggle fake profile detection dataset.
Project Title: Fake Social Media Profile Detection using Machine Learning

Overview:
This project focuses on identifying malicious, automated, and fake social media accounts to enhance user trust and platform security. By analyzing key account indicators—such as activity metrics, follower-to-following ratios, and metadata patterns—the system uses supervised machine learning models to accurately classify accounts as genuine or fake.

Key Features:

Automated Data Pipeline: Programmatically fetches and extracts the Kaggle debanshupal/fake-profile-detection-dataset using credentials via environment variables.

Exploratory Data Analysis (EDA): Visualizes user behavior metrics and feature correlations to highlight key indicators of bot activity.

Data Preprocessing: Cleans missing values, normalizes numerical attributes, and encodes categorical features for optimal model execution.

Supervised Classification: Evaluates machine learning algorithms to achieve high precision and recall in detecting fraudulent profiles.
